# Microsoft Office (Microsoft Graph / Office 365)

> A collection of APIs for Microsoft Office applications and services — Word, Excel, PowerPoint, Outlook, OneDrive, and Teams — reached programmatically through Microsoft Graph (the unified Microsoft 365 REST API, OData v4) and the Office JavaScript add-in APIs. Authentication is Microsoft Entra ID (Azure AD) OAuth 2.0. Generated by API Evangelist from the catalog; the provider does not publish an llms.txt.

## APIs

- [Microsoft Graph API](https://developer.microsoft.com/en-us/graph): Unified endpoint for Microsoft 365 services. baseURL https://graph.microsoft.com/v1.0
- [Word API](https://learn.microsoft.com/en-us/javascript/api/word): Office.js API for Word documents.
- [Excel API](https://learn.microsoft.com/en-us/javascript/api/excel): Office.js API for workbooks, worksheets, ranges, charts, tables.
- [PowerPoint API](https://learn.microsoft.com/en-us/javascript/api/powerpoint): Office.js API for presentations and slides.
- [Outlook Mail API](https://learn.microsoft.com/en-us/graph/api/resources/mail-api-overview): Mail, calendar, contacts, tasks.
- [OneDrive API](https://learn.microsoft.com/en-us/graph/api/resources/onedrive): Files and folders in OneDrive/SharePoint.
- [Teams API](https://learn.microsoft.com/en-us/graph/api/resources/teams-api-overview): Messaging, channels, collaboration.
